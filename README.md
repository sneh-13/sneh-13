## 🃏 Currently Building — Cardexa

<div align="center">

### [Cardexa.app](https://cardexa.app)

**A modern Pokémon TCG collection platform built for collectors.**

</div>

Cardexa is one of my main projects and an application I've been building from the ground up.

The goal is to create a fast, clean, and modern way to explore Pokémon cards, track collections, discover card variations, and monitor collection progress.

### Some of what I'm working on

```text
Card Catalog       → Browse cards, sets & variations
Collection System  → Track owned cards and collection progress
Search             → Quickly find cards and expansions
Authentication     → Secure user accounts and profiles
Infrastructure     → Production deployment, monitoring & security
Performance        → Image optimization, caching & fast page loads
```
